# Тестирование функций с помощью Pytest

Небольшой учебный проект, предназначенный для освоения автоматического тестирования кода на Python. Он демонстрирует применение ключевых возможностей библиотеки Pytest: работу с базовыми проверками (assert), параметризацию тестов, создание изолированных тестовых данных через фикстуры (fixtures) и валидацию ожидаемых исключений (exceptions).

## Установка (Installation)

**1. Клонирование репозитория:**
```bash
git clone https://github.com
cd pytest_project
```

**2. Создание виртуального окружения (лучшая практика!):**
```bash
python -m venv venv
# Для Windows:
venv\Scripts\activate
# Для Linux/macOS:
source venv/bin/activate
```

**3. Установка зависимостей:**
```bash
pip install -r requirements.txt
```

## Использование (Usage)

Для запуска всей тестов и получения детального отчета выполните в консоли:
```bash
pytest -v
```

Вы также можете запускать отдельные группы тестов с помощью зарегистрированных маркеров:
```bash
# Запустить только математические тесты
pytest -m math -v

# Запустить только тесты профиля пользователя
pytest -m user_profile -v
```

## Структура проекта

```text
pytest_project/
- .pytest_cache/        # Временный кэш pytest для ускорения повторных запусков
- venv/                 # Изолированное виртуальное окружение Python
- functions.py          # Основной код приложения (функции калькулятора, корзины, кошелька)
- test_functions.py     # Файл с тестовыми сценариями, фикстурами и параметризацией
- pytest.ini            # Файл конфигурации для регистрации кастомных маркеров
- README.md             # Документация проекта (этот файл)
```
